===== namepaces =====

In Amm, the string constants can be used as the class names (to be able to specify the classes using the JSON configuration).

=== **Amm.registerNamespace**: function (ns, hash) ===
	* registers a namespace
	* ns - string - namespace id
	* hash - object or function - namespace content

=== **Amm.registerFunction**: function (name, fn) ===
	* saves the function name for future retrieval. Name can have any characters.
	* name - function name to get with Amm.getFunction(name)

=== **Amm.getFunction**(strName, dontThrow) ===
	* searches for a function and returns it
	* strName - name of the function
		* if the value of type ''function'' is provided in place of ''strName'', it is be returned immediately
		* then searching for exact match of ''strName'', registered using ''registerFunction'' before, and return it if found
		* then try interpreting strName as a comma separated path, and search in the registered namespaces
		* not found - throw an exception
	* dontThrow - if true, exception won't be thrown in the absence of the result, and ''null'' is returned
	* anywhere, where Amm accepts a class name, ''Amm.getFunction()'' is used to search for the class' constructor.

To let Amm know, where to search for a class, a ''namespace'' needs to be registered. 

By default the three namespaces exist:

* **"Amm"** - all classes are there or in the nested classes/namespaces;
* **"v"** - shortcut for Amm.View.Html;
* **"t"** - shortcut for Amm.Trait

Identifiers of nested namespaces and classes are separated by a dot (''.'').

The namespace can be either a function(constructor), or an object.

=== Example ===

Creating new ''namespace'':

{{{code: lang="js" linenumbers="False"
SampleApp = {
	
	SampleClass: function() {
	},
	
	SampleClass2: function() {
	}

}

SampleApp.SampleClass.SubClass = function() {};
Amm.registerNamespace ('SampleApp', SampleApp);

}}}


now we can get the constructors like this:

{{{code: lang="js" linenumbers="False"

//>
Amm.getFunction('SampleApp.SampleClass')

//< function SampleClass()

//>
Amm.getFunction('SampleApp.SampleClass.SubClass')

//< function SubClass()
}}}


since Amm.getFunction can retrieve a function as an argument, these calls are identical:

{{{code: lang="js" linenumbers="False"
//>
Amm.getFunction('SampleApp.SampleClass') === Amm.getFunction(SampleApp.SampleClass);

//< true
}}}


===== class names, inheritance and interfaces =====

In lots of places in Amm there are checks that the argument is an instance if required class. Since Javascripts instanceof doesn't support the Amm flavor of inheritance. // TODO: use the proper JS inheritance

So, to implement that, Amm objects have special properties to denote the name of the class of the object.

==== Creating a simpliest class ====

The prototype must have a property "Namespace.Class.Name" with the name ''"__CLASS__".''

For example, we use SampleApp from the former example to create the descendant of Amm.WithEvents.Proper creation of the basic class with Amm is done like this: 

{{{code: lang="js" linenumbers="False"
SampleApp.SampleClass = function(options) {
	Amm.WithEvents.prototype.call(this, options);
}

SampleApp.SampleClass.prototype = {
	"SampleApp.SampleClass": "__CLASS__"
}
}}}

==== Class check ====

=== Amm.getClass: function(object) ===
	* returns
		* string - class of the object **object**
		* if the class cannot be determined - returns null
	* implemented by searching for the property with the value "__CLASS__", and returning its key

=== Amm.is: function(item, className, throwIfNot) ===
	* returns true, if **item** is an instance of **className** //or inherits it//.
	* if **className** - is an array, returns true, if item is one of / descendant of //any// of the specified classes
	* **throwIfNot** - if it should throw an exception if the check didn't succeed
		* true - if true, throws exception like "item must be an instance of {className}; given: {type description}"
		* string with the parameter name - to make a friendlier exception - the exception will have it instead of ''item'' word

=== Example ===

{{{code: lang="js" linenumbers="False"
//>
obj = new SampleApp.SampleClass()

//< object

//>
Amm.getClass(obj)

//< 'SampleApp.SampleClass'

//>
Amm.is(obj, 'SampleApp.SampleClass')

//< true

//>
Amm.is(obj, SampleApp.SampleClass) // no quotes - use the constructor

//< true

//>
Amm.is(obj, 'Amm.WithEvents')

//< false
}}}


=== Using Amm.is for checking the function arguments' classes ===
Using Amm.is(item, className, throwIfNot) with a parameter name instead of  throwIfNot is handy to check for the types early in the function call; for example, this function expects for Amm.WithEvents:

{{{code: lang="js" linenumbers="False"
function listEventHandlers(inspectedObject, eventName) {
	Amm.is(inspectedObject, "Amm.WithEvents", "inspectedObject");
	// ...
}

//>
listEventHandlers(new Amm.Builder.Ref, "someEvent")

//< Uncaught Error: inspectedObject must be an instance of Amm.WithEvents; given: Amm.Builder.Ref
}}}

that means, for methods with multiple parameters, error messages will report what parameters are incorrect.

This approach is used everywhere in the Amm, where class checks take place.

=== Inheritance ===

To subclass a class, we have a method

=== Amm.extend: function(subClass, parentClass, dontIndicateParent) ===
	* makes **subClass** a descendant of parentClass
	* **subClass**: function - descendant constructor
	* **parentClass**: function - ancestor constructor
	* **dontIndicateParent**: don't update ancestor class property from ''__CLASS__'' to ''__PARENT__''

As with the many other libraries, this method adds members of the ancestor to the prototype of the descendant, if they arent's already in place.

Also, if in the ancestor prototype exists the member with the value ''__CLASS__'', it will be replaced with the value ''__PARENT__''.

What Amm.is(object, className) does - is checking for condition

{{{code: lang="js" linenumbers="False"
object[className] === "__CLASS__" || object[className] === "__PARENT__"
}}}

This way ''is()'' supports the inheritance.

=== Example ===

{{{code: lang="js" linenumbers="False"
SampleApp.SampleClass = function(options) {
	Amm.WithEvents.prototype.call(this, options);
}

SampleApp.SampleClass.prototype = {
	"SampleApp.SampleClass": "__CLASS__"
}

Amm.extend(SampleApp.SampleClass, Amm.WithEvents);

//>
obj = new SampleApp.SampleClass()

//< object

//>
Amm.getClass(obj)

//< 'SampleApp.SampleClass'

//>
Amm.is(obj, 'SampleApp.SampleClass')

//< true

//>
Amm.is(obj, 'Amm.WithEvents')

//< true

//> 
Amm.is(obj, 'Amm.Element')

//< false

//>
obj['SampleApp.SampleClass']

//< "__CLASS__"

//>
obj['Amm.WithEvents']

//< "__PARENT__"

//>
Amm.is(obj, SampleApp.SampleClass) // no quotes - use the constructor directly

//< true
}}}


==== Multiple inheritance ====

Nothing stops us from calling Amm.extend multiple times; parent classes will be registered every time. It's important not to forget to call all parent constructors in the descendant one. We still have one class name (returned by ''Amm.getClass()'' and correctly working ''Amm.is()'' for all ancestor classes:

=== Example ===

{{{code: lang="js" linenumbers="False"
// from Amm implementation:

Amm.View.Html.Collection = function(options) {
    Amm.registerItem(this);

    // first parent constructor:
    Amm.View.Html.call(this);

    // own code
    this._mappingProp = '_map_vhc_' + this._amm_id;

    // second parent constructor:
    Amm.View.Abstract.Collection.call(this, options); 
};

Amm.View.Html.Collection.prototype = {

    'Amm.View.Html.Collection': '__CLASS__', 
    
    // ...methods...

}

// inherit first parent
Amm.extend(Amm.View.Html.Collection, Amm.View.Html);

// inherit second parent
Amm.extend(Amm.View.Html.Collection, Amm.View.Abstract.Collection);

//>
htmlCollection = new Amm.View.Html.Collection()
Amm.is(htmlCollection, 'Amm.View.Html')

//< true

//>
Amm.is(htmlCollection, 'Amm.View.Abstract.Collection')

//< true
}}}

==== Inheriting properties, defined by Object.defineProperty ====

If in the parent prototype there were properties defined using Object.defineProperty, they'll be re-defined in the descendant class (only if there are get, set, or a property is a read-only one, since "vanilla" writeable props without accessor methods are created just by copying the prototype).

==== Additional inheritance functions ====

* **constructor.beforeExtend:** function (subClass, parentClass, dontIndicateParent): boolean
* **constructor.afterExtend**: function (subClass, parentClass, dontIndicateParent)

If we add functions to a constructor function (not to the prototype!) such as beforeExtend and/or afterExtend, Amm.extend will call them before/after modifying the descendant prototype.

If beforeExtend returns true, modification of the descendant prototype using Amm.extend will be skipped (it's assumed the necessary work is already done by ''beforeExtend'' method).

The functions beforeExtend/afterExtend won't be inherited by the descendant constructor on their own, but they can add themselves there if needed.

==== Interfaces ====

Interfaces allow to let others know that the object supports particular set of the methods. At the present time it is not enforced - if we locate an interface tag in the ojbect, we trust his word on it.
* Amm.is() checks for interfaces;
* Amm.extend() copies interface tags along with the prototypes.

Interfaces have simple names like "Focusable" or "MetaProvider".

=== Amm.getInterfaces(object, commonWithObject) ===
* returns Array - list of the interfaces of the **object**
* **object** - object to get the list of the interfaces
* **commonWithObject** - second object; if provided, the list will have only the interfaces that both objects have // Note: what was the use case?

=== Amm.hasInterfaces(object, interfaces, throwIfNot) ===
* returns true, if the object implements **object** //every// interface from the **interfaces** list
* **interfaces**: string|Array - one to many interfaces
* **throwIfNot**: 
	* bool - if we should throw an exception if the object doesn't fulfill the requirements
	* string - if the param ''throw'' is a string, it will be used as a paramter name in the exception text to make it more readable (like Amm.is())

=== Example ===

{{{code: lang="js" linenumbers="False"
MyClass = function() {}

MyClass.prototype = {
	"Boring": "__INTERFACE__",
	"Dummy": "__INTERFACE__"
}
//>
instance = new MyClass()
Amm.getInterfaces(instance)

//< ["Boring", "Dummy"]

//>
Amm.hasInterfaces(instance, "Boring")

//< true

//>
Amm.hasInterface(instance, ["Dummy", "Boring"])

//< true

//>
Amm.hasInterface(instance, ["Dummy", "Boring", "Other"])

//< false

//>
Amm.is(instance, "Boring")

//< true
}}}

==== Requirements ====
In some cases we need to check, if the object meets some conditions, in the runtime.

=== Amm.meetsRequirements(object, requirements, paramName) ===
* checks, if the object **object** supports one of provided combinations of classes/interfaces/methods
* returns true, false, or throws an Exception, if **paramName** is a string
* **object** - object to check
* **requirements** - string|Array - requirements list
	* in the full form it's a array of an arrays
		* format: [ [rq1, rq2], [rq3, rq4], rq5, ... ] where rqX is a class, interface, or method name
	* check returns TRUE only if the object satisfies all conditions from any of the sub-arrays. For example above it's (rq1 AND rq2) OR (rq3 AND rq4) OR rq5
	* if sub-array has only one requirement, it can be provided directly
	* string: "Ns.ClassName" is the sanme as Ns.ClassName
* **paramName**: undefined|string - if provided, generate an exception using ''paramName'' in the text for readability (as in Amm.is())

=== Example ===
{{{code: lang="js" linenumbers="False"
MyListClass = function() {}
MyListClass.prototype = {
	getList(): function() { return []; },
	setList(): function ( reuturn []; }
}
MySecondListClass = function() {
        "WithList": "__INTERFACE__"
}

//>
myList = new MyListClass()
mySecondList = new MySecondListClass()

//>
Amm.meetsRequirements (myList, [["getList", "setList, "deleteList"]])

//< false // since myList doesn't have the method deleteList(), and we need all three

//>
Amm.meetsRequirements (myList, ['WithList', ["getList", "setList"]])

//< true // since condition set 2 is matched

//>
Amm.meetsRequirements (mySecondList, ['WithList', ["getList", "setList"]])

//< true // since condition set 1 is matched, and the object has interface WithList
}}}

===== Amm.createClass(name, parent, proto, constructorFn) =====
Allows to (relatively) quickly create classes with the sets of [[properties]], inheritance and all required members in the prototypes.

// Note@2026-10-18: how about creating a lazy class declaration using the callbacks? If we check using Amm.is with a callback of non-created class yet, is() always returns false - class isn't "loaded" yet.

* **name**: string|null - name of new class in the format Namespace.SubNameSpace.ClassName. All namespaces must exist and be registered before using them in the class declaration. The class created must NOT be registered on the contraty. If not provided, the name isn't set (and the prototype doesn't get the tag '''Namespace.SubNameSpace.ClassName': __CLASS__'').
* **parent**: function|null - path to the ancestor class, or its constructor. Null can be provided if the we don't inherit anytihng.
* **proto**: object|null - prototype of the new class. May have property definitions, as described below.
* **proto.prop__<propName>**: property definition
	* a. proto.prop__<propName>: defaultValue, where defaultValue isn't an object: creates a property, getter, setter, change event, and class member with the name propName (Object.defineProperty)
	* b. prop.prop__<propName>: object - allows to specify separate params for Amm.createProperty. Keys: defaultValue, onChange, defineProperty.
* **constructorFn: function|null** - constructor for the new class. If not provided, default constructor is given:
	* call the parent constructor with the same arguments, if we inherited anything;
	* if we don't have an ancestor, by default it's function(options) { Amm.init(this, options); }

Returns the created function.

{{{code: lang="js" linenumbers="False"
var GuyClass = Amm.createClass('GuyClass', 'Amm.WithEvents', { 
	prop__name: null,
	prop__birthDate: null
});

var guy = new GuyClass ({
	name: 'John', 
	birthDate: '01.01.2001',
	on__nameChange: function(newName) { console.log("new name is", newName); }
});

//>
guy.name = 'xx';

//<< "new name is", "xx"

//>
guy.getBirthDate();

//<< '01.01.2001'

//>
Amm.getClass(guy);

//< 'GuyClass'

//>
Amm.is(guy, 'Amm.WithEvents');

//< true
}}}
