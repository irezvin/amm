====== Project structue and building ======
Created Friday 26 February 2021

File tree in Amm looks like this:

Amm.js
Amm/Operator.js
Amm/Operator/Range.js
Amm/Operator/Range/Condition.js

Basic rules:
* one class - one file
* class or namespace with the name Root.Parent.Child is located in the Root/Parent/Child.js, and so on.

To build the project, use build/amm-utils.php tool. It can be used to
* a. generate one compressed file using the uglifyjs; can also be run as build/build.php which updates the files in ../dist;
* b. generate list of <script> tags in the required order.

How the single-file build is done:

* main build routine argument is the name of the "root" namespace (`Amm` in our case)
* all classes have the format RootNamespace.SubIdent.SubSubIdent and so on (starting with capital letters, dot-separated)
* first type of dependency: names of the classes
	* presence of "Class.Name.SubName.prototype" string means that the class Class.Name.SubName is defined here, and that it requires files Class.js, Class/Name.js, Class.SubName.js etc.
* second type of dependency: inheritance. String "Amm.extends(Child.Class.Name, Parent.Class.Name)" means that **before** the file, where it was mentioned, we need to include Parent/Class/Name.js
* third type: forced dependency (rare case). To force including something, add a comment like "// Amm.extends(...)", to trigger inheritance-type dependency without actuall executing the code.
