====== Advantages of using the basic ecmascript subset ======

Created Friday 26 February 2021

* minimal dependency on the build tools (only php build script and uglifyjs)
* easy-to-read non-compressed code in its simple form (multiple `script` tags);
  easy to find a mistake because it immediately shows at the source line;
* no compile step
  * easy to debug
  * easy to make changes and update the page
* JS source always mentions the full class names
  * it's easy to trace the dependencies
  * it's relatively easy to rename the classes (global search and replace plus changing the file name)
* any class can be easily found due to direct mapping between classes and files: Amm.Operator.Range.Condition is located in Amm/Operator/Range/Condition.js
* absence of strict typing eases the work and provides us with multiple inheritance and trais, including the dynamic ones
* instead of the strict typing, we use strict class checks using Amm.is() where we know what class we expecting.
* in places where it's critical, parameters' type and bound checks are in place
* there is no "magic" and "convention over configuration"; I hope it simplifies reading the code.
