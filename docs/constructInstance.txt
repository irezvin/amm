====== Standardized approach to creation of the objects (Amm.constructInstance) ======
Created Monday October 05, 2020

As described [[options|here]], most constructors in Amm and derived solutions can accept ''options'' hash with the property values that are set upon creation. (And given that many classes extend Amm.WithEvents, event handlers can be set that way too.)

By adding ''class'' key to the ''options'', which specifies the instance's constructor, the hash turns into the self-sufficient specification of the created instance: we can locate the constructor, and have its arguments.

That's how methods //Amm.constructInstance()// and //Amm.constructMany()// operate.

It is important to differentiate between the options, and the instance of the class.

**Options** is an object (a hash) with the future instance properties, sometimes including the ''class'' property, pointing to the constructor.
**Instance of a class** is a finished result of a constructor function work, for which Amm.getClass(instance) returns a non-empty result.

(In Amm terminology - comments, methods and property names - often appears "prototype" term, that usually means ''options'' hash plus the ''class'' property; not to be confused with Javascript prototype, unless stated otherwise.)

===== Amm.constructInstance: function(options, baseClass, defaults, setToDefaults, requirements) =====

Creates and configures instance using the ''options'' hash and/or makes sure that the supplied instance meets the requirements. 

Returns created or supplied instance, or throws an exception.

* **options**:  object|string - options of the constructed instance, the instance, or the class name.
	* If the string is provided, it's the same as supplying { "class": options }, meaning the string is interpreted as the class name.
	* If ''options'' is an instance, the constructor isn't called, only the ''defaults'' are set, and ''requirements'' are checked - if they were provided.
* **baseClass**: undefined|function|string - default constructor which doubles as a mandatory base class.
	* if ''options.class'' isn't provided, ''baseClass'' is used as default constructor;
	* created or supplied instance is checked to be instance of (or descendant of) a ''baseClass'' using ''Amm.is()''. If it's not the case, exception is triggered.
* **defaults**: object - so called "default options", which are added to the ''options'', except for the keys that are already there (''options'' keys take precedence over ones in ''defaults'').
* **setToDefaults**: boolean - whether to set properties of ''defaults'' to the instance that was supplied instead of the ''options'' hash.
* **requirements**: if provided, instance is checked to fulfill ''Amm.meetsRequirements(instance, requirements)'', and exception is thrown if it isn't.

==== Example ====

Let's define two classes: ''Person'' with the ''name'', ''birthDate'' and ''occupation'' properties, and ''Employee'' - descendant, with additional ''position'' and ''salary'' properties.

{{{code: lang="js" linenumbers="False"
var Sample = {};

Amm.registerNamespace('Sample', Sample);

Amm.createClass('Sample.Person', 'Amm.WithEvents', {
	prop__name: null,
	prop__birthDate: null,
	prop__occupation: null
});

Amm.createClass('Sample.Employee', 'Sample.Person', {
	prop__position: null,
	prop__salary: null
});
}}}

===== Amm.constructMany: function(manyOptions, baseClass, defaults, keyToProperty, setToDefaults, requirements) =====

Creates/configures/checks multiple instances using Amm.constructInstance(). Can assign key or index for every instance. Always returns a javascript Array.

* **manyOptions**: object|Array
* **keyToProperty**: string
* **baseClass, defaults, setToDefaults, requirements** - see ''Amm.constructInstance()''.
