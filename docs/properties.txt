====== properties ======
Created Thursday, September 17, 2020

===== "Properties" of the Amm flavor =====
"Property" is a combination of:
* setter (set<Property>)
* getter (get<Property>)
* changeEvent (out<Property>Change)

changeEvent should fire only when the new value differs from the old one. By equal usually strict equality is meant (===).

**Important!** In the method names get..., set..., out...Change, the property name starts with the capital letter.

Access to the properties in Amm implementation is done using setters and getters:
* value = instance.get<Property>()
* instance.set<Property>(value)

In the framework-based apps the creation of the properties can be simplified using Object.defineProperty, or Amm.createProperty.

===== Example of the property implementation =====

To create a class with the minimally implemented "value" property, the following code is needed:
{{{code: lang="js" linenumbers="False"
ClassWithValue = function(options) {
	Amm.WithEvents.call(this, options);
}

ClassWithValue.prototype = {
	
	'ClassWithValue': '__CLASS__',
	
	_value: undefined,
	
	getValue: function() {
		return this._value;
	},
	
	setValue: function(value) {
		var oldValue = this._value;
		if (value === oldValue) return;
		this._value = value;
		this.outValueChange(this._value, oldValue);
	},
	
	outValueChange: function(value, oldValue) {
		return this._out('valueChange', value, oldValue);
	}
}
Amm.extend(ClassWithValue, Amm.WithEvents);

var Sample = new ClassWithValue({
	value: 50,
	on__valueChange: function(value, oldValue) {
		console.log('value changed from', oldValue, 'to', value);
	}
});

//>
Sample.getValue()

//< 50

//>
Sample.setValue(30)

//<< 'value changed from', 50, 'to', 30

//>
Sample.setValue(30)

//<< // nothing is shown in the console

//>
Sample.setValue('30')

// << 'value changed from', 30, 'to', '30' // since the comparison is strict
{{{code: lang="js" linenumbers="False"

===== Generating the property boilerplates using the command line tool =====

The implementation above is simple, but already cumbersome. To ease creation of such code, a tool mk.php from Amm project dir can be used.

Call format:

{{{code: lang="sh" linenumbers="False"
#>
./mk.php -p <propName1> [<propName2> <propName3> ...]
}}}

The tool returns "protected" members for the properties _propName1, _propName2... at the start of the code (default value is null), and get-, set- and out-methods in the code that follow next. (The code is very close to the example above).

To immediately copy this definition to the clipboard, ''xclip'' can be used:
{{{code: lang="sh" linenumbers="False"
#!/bin/bash
php /path/to/mk.php -p $* | xclip -i -selection clipboard
}}}

===== What to do in the setter and getter (part 1) =====

What is sometimes added manually to the setter implementation:

* coercing the argument to the required type. For example, if we expect a boolean value, we might convert argument to it with value = !!value. It saves us from generating change event for the semantically identical values.
* typecheck. Exception needs to be generated //before// changing the member value and generating the event.

We can add delayed initialization or delayed evaluation to the getter, that don't need to be done unless we retrieve the value with it.

===== Using Amm to create the properties =====
If we need to quickly define couple of properties without writing a boilerplate from the above, ''Amm.createProperty'' can be used.

==== Amm.createProperty(target, propName, defaultValue, onChange, defineProperty) ====
* creates  getter, setter and changeEvent, also "protected" member field to implement property **propName**
* can call object.defineProperty for the property, to make it available using target.<PropName> or target[propName]
* if getter, setter, changeEvent, or member field already exist, they won't be overwritten, so we can still create some of them by hand
* **target**: **object** - object to have the property added
* **propName**: string - property name (starting with the lowercase letter)
* **defaultValue**: mixed - default value (''undefined'' will be used, if the ''defaultValue'' is not provided)
* **onChange: undefined|function|object** - optional function that will be called in the case, when new value in the setter isn't equal to the old one
	* If the setter already present in the prototype, this parameter is ignored
	* **function onChange(value, old, propName)**: is called if the new value is not equal (===) to the old one, but before triggering the event. To avoid triggering the event, the function can set the member field to the new value.
	* If onChange is an object, it can have two keys: ''before'' and ''after''.
	* **function onChange.before (value, old, propName)** - is called before the internal comparison. 
	* if ''onChange.before'' returns anything except the ''undefined'', it becomes the new value: value := onChange.before(value)
	* **function onChange.after** - the same meaning as function-valued onChange(), described above
* **defineProperty:** boolean - if TRUE, javascript property with the name ''propName'' will be created using object.defineProperty. Methods get and set will be added, calling getter and setter respective methods. Since the closure uses the names of the functions and not the functions themselves, polymorphism is adhered in the descendant classes. The only shortcoming is that onChange method/methods cannot be overridden in the descendant - only the whole setter can be re-defined.

==== Example ====

In the example below we create property not of an instance, but of a prototype, to let the instances have this property:
{{{code: lang="js" linenumbers="False"
var ClassWithNumber = function(options) {
    Amm.WithEvents.call(this, options);
}

ClassWithNumber.prototype = {	
    'ClassWithNumber': '__CLASS__',
}

Amm.createProperty(ClassWithNumber.prototype, 'number', 0, {
    before: function(number, old) {
        if (typeof number === 'number') return;
        var newValue = parseFloat(number);
        if (isNaN(newValue)) {
            throw Error("Please specify proper number; given: '" + number + "'");
        }
        return newValue;
    },
}, true);	
    
Amm.extend(ClassWithNumber, Amm.WithEvents);

var Sample = new ClassWithNumber({
	on__numberChange: function(number, oldNumber) {
		console.log('number changed from', oldNumber, 'to', number);
	}
});

//>
Sample.number

//< 0

//>
Sample.number = 30.5

//<< 'number changed from', 0, 'to', 30.5

//>
Sample.number = '20.5'

//<< 'number changed from', 30.5, 'to', 20.5

//>
Sample.number

//< 20.5 // converted to a number

//>
Sample.number = 'xxx'

//<< Uncaught Error: Please specify proper number; given: 'xxx'
}}}

==== Example with the inheritance ====
(continuing the example above)

{{{code: lang="js" linenumbers="False"

var ClassWithInt = function(options) { return ClassWithNumber.call(this, options); };

// class that rounds the property values
ClassWithInt.prototype = {
    'ClassWithInt': '__CLASS__',
    _number: 0,
    setNumber: function(value) {
        var newValue = value;
        if (typeof newValue !== 'number') newValue = parseFloat(value);
        if (typeof newValue === 'number' && !isNaN(newValue)) value = Math.round(newValue);
        return ClassWithNumber.prototype.setNumber.call(this, value);
    }
};

Amm.extend(ClassWithInt, ClassWithNumber);

var Sample2 = new ClassWithInt();
//>
Sample2.number

//< 0

//>
Sample2.number = 20.1

//>
Sample2.number

//< 20 // rounding worked using the Math.round()

//>
Sample2.number = '20.7'
Sample2.number

//< 21 // conversion and rounding was applied

//>
Sample2.number = 'zzz'

//<< Uncaught Error: Please specify proper number; given: 'zzz' // ancestor code was triggered

}}}

===== Amm functions that work with the properties =====

==== Amm.detectProperty: function(object, property, outCaps) ====
Returns **true**, if for property **property** of the object **object** are defined getter, setter and changeEvent; **false**, if any of these parts is missing.  // Note @2026-10-18: that complicates adding read-only properties

Fills-out outCaps with the info of the accessor methods.

* **object**: object - object that we check for the presence of the property
* **property**: string - name of the property
* **outCaps**: undefined|object - hash to put the keys into //independent of the outcome of the check//
	* **outCaps.getterName**: string|null - name of the getter function, if found (get<Property>); null, if not found
	* **outCaps.setterName:** string|null - name of the setter function, if found (set<Property>); null, if not found
	* **outCaps.eventName:** string|null - name of the event <property>Change, if object.hasEvent(eventName) returns true; null, if not found

==== Amm.getProperty: function(object, property, defaultValue, args) ====
Returns value(s) of one or several properties for one or several objects.
* **object**: object|[object, object...] - object or objects to get the property/properties of 
* **property**: string|[string, string...] - name(s) of the property(ies) to get value(s) of
	* value "class" is a reserved name of the property and returns Amm.getClass(object) - only if the object doesn't have a property with the name "class"
* **defaultValue**: undefined|mixed - default value to return if the property isn't found
* **args**: undefined|mixed|Array - one or many getter args (if we want to retrieve multiple property values, all getters will receive the same args)
* returns mixed|object|[mixed]|[object] - value of one or many properties for one or many objects

Types of returned properties:
| object    <| property    <| result                                                                     <|
|:-----------|:-------------|:----------------------------------------------------------------------------|
| object     | Array        | hash with property names and their values   								  |
| Array      | string       | array* of the values of property value for every item in object Array       |
| Array      | Array        | array* of hashes of property: value pairs for every object    	          |
| object     | string       | singular value of object.get<Property>(), or default value                  |


Note for "array*" above:

in the case when getProperty() receives an array of object as the first arg, and returns Array, that Array instance has additional method added: getProperty(property, defaultValue, args), that calls Amm.getProperty(this, property, defaultValue, args). That allows to chain the calls like this:

{{{code: lang="js" linenumbers="False"
var recordStates = Amm.getProperty(records, 'mm').getProperty('state'); 

// same as:
var metas = Amm.getProperty(records, 'mm'); 
recordStates = Amm.getProperty(metas, 'state'); 
}}}


==== Amm.setProperty: function(object, property, value, throwIfNotFound, args) ====

Sets ''property'' of the ''object'' to the ''value''. Same as with the Amm.getProperty, we can set value(s) a. of many objects; b. of many properties (if the hash is given) and ''value'' === undefined; c) of multiple properties of multiple objects.

* **object**: object|[object, object...] - object or objects to set the properties of
* **property**: string|object - name of property, or hash with {property: value} pairs
* **value**: mixed|undefined - value to set (needs to be undefined for multiple-property form)
* **throwIfNotFound**: boolean - if true, not finding a property will result in an exception
* **args**: undefined|mixed|Array - zero/one/multiple arguments to the setter(s)
* returns nothing

===== Property arguments: what to do in the setter and getter (part 2) =====

One of the extensions of the ''property'' idea in Amm is that both setter and getter can have arguments. This is called property arguments. Most properties don't have the arguments; but when they do, it's assumed that the argument allows to get/set not the property in full, but some of its parts.

Example of the property argument is ''className'' of Amm.Trait.Visual.
If we set ''className'' w/o argument, it's going to update the whole ''class'' attribute of the DOM node. If className(part) := true, it's identical to jQuery.addClass(part), and className(part) := false identical to jQuery.removeClass(part). Getting getClassName(part) returns true, if this substring is present in the whole ''class'' of the element.

Example:

{{{code: lang="js" linenumbers="False"
//>
foo.setClassName("table empty")

//>
foo.getClassName()

//< "table empty"

//>
foo.getClassName("table") 

//< true

//>
foo.getClassName("empty")

//< true

//>
foo.setClassName(false, "empty") // removed "empty"
foo.getClassName()

//< "table"

//>
foo.setClassName(true, "empty") // added "empty"
foo.getClassName()

//< "table empty"
}}}


It's important to keep the following in mind:

* arguments are not required
* the setter always has the provided value as the //first// argument; additional (property) arguments follow //after// the necessary value-to-set argument;
* behavior of out<Property>Change() event isn't affected by the arguments.

===== Syntax of accessing properties from Amm.Expression =====

* object.property
* object.property::firstArg::secondArg - with the parameters (values of the arguments are string identifiers, or constants)
* object.property::{expression, expression} - expressions used as the arguments
* object[expression] - expression used as the property name
* object[expression]{expression, expression} - expressions are used both as property names and as property arguments
