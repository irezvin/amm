    via the __CLASS__ property, if the `class` is present, return the instance

2021-10-14
==========

?   Array: add new events

    -   spliceInfo: event splice with the extra parameter `spliceInfo`
        spliceInfo is
            insert   [ insertIndex, insertIndex, ... ]
            cut      [ cutIndex, cutIndex, ... ]
            reinsert [ [cutIndex, insertIndex], ... ]
        // 27.09.26: should make this structure deep-immutable
            
    -   pan:
        removal of some elements from one end, and adding some (different)
        elements to the other end as a single action, leaving some number
        of elements inside untouched
        -   cutFromTail: true/false 
            -   true: elements were removed from the tail of the array,
                added to the head;
            -   false: vice versa
        -   cut: [ item, item... ] - removed items
        -   insert: [ item, item... ] - added items
