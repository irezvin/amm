+   Important!! Amm.Data.Model.mm: if the multiple Models or Records have the same prototype,
    they share *common* instance of FieldMeta provider (this behavior can be overridden
    by some options' key). We need this for cases such as
    
        var people = new Amm.Data.Collection({
            keyProperty: 'name',
            instantiateOnAccept: true,
            instantiator: new Amm.Instantiator.Proto({
                overrideProto: true,
                proto: {
                    'class': 'Amm.Data.Model',
                    mm: {
                        meta: {
                            name: {
                                label: 
                                required: true
                            }
                        },
                    }
                },
            })
        });

    at the moment, *every* collection item's instance will have FieldMeta re-created 
    (contrary to the case of using the Mapper). But according to the common sense
    they should share one.
    
    -   (best option) add FieldMeta or MetaProvider to Amm.Data.Collection,
        it's going to be created once (explicitly), and injected to the objects
        during association with the Collection, or instantiation by it.
        
    -   Amm.Data.Collection.modelPrototype, Amm.Data.Collection.fieldMetaProvider
