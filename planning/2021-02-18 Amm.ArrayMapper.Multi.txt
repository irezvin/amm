2021-02-18 Amm.ArrayMapper.Multi
================================

Tasks
-----

-   for every source object that passed the filter, the groups from 0 to N object are extracted
    (groups appear in the order that is defined by the `sorter`)

-   to achieve that, we use Amm.ArrayMapper.Extractor extends Amm.ArrayMapper.AbstractExtractor     
    -   src - property or expression (null means return the object)
    -   onExtract - event(srcObject, retValue)
    -   expandCollections - t/f - if the result is collection, it's observed, and the contents
        is returned
    -   addSrcToResult: never | ({before | after} {ifAny | ifMatch | ifNone}):
        do we add the source object to the list of result objects
            -   never

            -   before: to the start of the list
            -   after: to the end of the list

            -   ifAny: always
            -   ifMatch: only for non-empty result set
            -   ifNone: only when there is no other objects in result set
    
-   Amm.ArrayMapper.MultiExtractor extends Amm.ArrayMapper.AbstractExtractor
    -   filter (may be borrowed from ArrayMapper)
    -   matches (synchronized with the filter)
    -   extractors (assoc array: matchValue => extractor)
    -   defaultExtractor
    
-   if `instantiator` is present, each object of dest group goes through it
-   all resulting objects appear in the `dest`
-   groups order matches the objects order
-   order of the objects in the group is the original one

-   ability to provide extra values to expression-using `filter` and `sorter`
    for every object (`extraVars`), which we can reference in the expressions

-   maybe in the future `destFilter`, `destSorter` will be added to filter/sort
    objects in the groups (both will have additional variables such as
    source object, it's index, `match` values in the `srcFilter`)

    -   important! `sorter` needs `onCompare` extra method, called when the list
        of the observed objects or their `matches` change. `destSorter` will
        first ensure, that the order of the objects in the groups didn't change,
        and only after that compare their matches. It will allow us to use a single
        sorter for all results.
